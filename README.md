# Sales Data Analysis Project

This project analyzes sales data using Python's Pandas and Matplotlib libraries, executed within an Anaconda environment. It includes data cleaning, basic statistics, and visualizations.

## Overview
This project uses a sample sales dataset to perform various data analysis tasks, such as:
- Cleaning data
- Generating basic statistics
- Visualizing the data using different plots (line charts, bar charts, histograms)

## Dataset
The dataset used in this project contains information about sales, including:
- Product names (e.g., Laptop, Headphones, Monitor)
- Region of sales
- Quantity sold
- Total sales amount
- Date of transaction

## Analysis
The analysis covers:
1. Loading and cleaning the dataset
2. Calculating basic statistics such as mean, median, and sum for different variables
3. Grouping data by categories (e.g., region or product) and performing calculations such as total sales or average sales.

## Visualizations
Various visualizations created include:
- Line chart of sales over time
- Bar chart comparing average sales across products
- Histogram of total sales distribution
- Scatter plot to visualize relationships between quantity sold and total sales
